# 사내 AI Agent 7개 유형 가이드

회사의 Agent는 단순히 부서별로 하나의 만능 Agent를 구축하는 방식이 아니라, 업무 책임과 시스템 권한 및 실행 위험 수준에 따라 구분하는 것이 좋습니다.

## 전체 구조

```text
                         사용자 요청
                              │
                              ▼
                    7. 업무 배정 Agent
                   요청을 확인하고 업무 배정
                              │
        ┌─────────┬─────────┬─────────┬─────────┐
        ▼         ▼         ▼         ▼         ▼
    지식답변    콘텐츠생성   데이터분석   의사결정지원   업무프로세스
      Agent       Agent       Agent        Agent          Agent
                                                        │
                                                        ▼
                                                  실행 작업 Agent
```

## 7개 Agent 유형

| 유형 | 주요 역할과 회사 업무 예시 | 제공해야 하는 데이터 | 권장 데이터 형식 | 시스템 권한 |
|---|---|---|---|---|
| 📚 **1. 지식 질의응답 Agent** | 사내 규정, 업무 절차 및 문서에 관한 질문에 답변<br>예: 재무 규정, HR 정책, IT 문의 | 사내 규정, 업무 매뉴얼, FAQ, 표준 답변, 적용 대상, 유효기간, 원문 출처 | Word·PDF 원문 + Excel·CSV FAQ 목록 | 일반적으로 읽기 전용 |
| ✍️ **2. 콘텐츠 생성 Agent** | 문서 작성, 요약, 번역 및 자료 생성<br>예: 보고서, 이메일, 계약서 초안, 회의록 | 승인된 문서 예시, 문서 템플릿, 작성 목적, 대상 독자, 문체 가이드, 참고 자료 | Word·PPT·Markdown 템플릿 + Excel 관리 목록 | 저위험 범위 내 쓰기 가능 |
| 📊 **3. 데이터 분석 Agent** | 데이터를 조회하고 지표를 계산하며 이상 원인을 분석<br>예: 예산, 매출, 비용 및 경영 분석 | 원천 업무 데이터, 데이터 항목 정의, KPI 계산식, 기간, 통화, 단위, 결측치 처리 기준 | Excel·CSV·데이터베이스 테이블 + 데이터 정의표 | 일반적으로 읽기 전용 |
| 🧭 **4. 의사결정 지원 Agent** | 여러 대안을 비교하고 예측 및 권고안 제공<br>예: 현금흐름 예측, 공급업체 선정, 리스크 평가 | 비교 대상, 평가 기준, 기준별 가중치, 필수 조건, 리스크 기준, 과거 사례 | Excel 평가표 + 관련 Word·PDF 자료 | 권고만 제공하고 직접 결정하지 않음 |
| 🔄 **5. 프로세스 협업 Agent** | 여러 단계의 업무 프로세스를 연결하고 진행<br>예: 비용 정산, 구매 신청, 임직원 입사 처리 | 업무 단계, 입력·출력 자료, 담당자, 처리 조건, 승인 규칙, 예외 처리, 처리 기한 | Excel 프로세스표 또는 BPMN·흐름도 | 여러 내부 시스템 호출 가능 |
| ⚙️ **6. 실행 작업 Agent** | 업무 시스템에서 실제 작업을 수행<br>예: 지급 요청, 세금계산서, 구매 주문 생성 | MCP·API 명세, 필수 입력값, 실행 조건, 검증 규칙, 승인 정보, 중복 방지 및 실패 처리 기준 | 업무용 Excel 입력표 + 시스템용 JSON·MCP·API 명세 | 시스템 쓰기 가능, 위험도 높음 |
| 🚦 **7. 업무 배정 Agent** | 사용자 요청을 이해하고 적절한 전문 Agent에 업무를 전달<br>예: 재무, HR, 구매 Agent에 요청 배정 | Agent 목록, Agent별 역할, 지원 업무, 입출력 형식, 실행 순서, 연결 및 실패 처리 규칙 | Excel Agent 관리표 + 시스템용 JSON 설정 | Agent 간 업무 배정 및 협업 관리 |

## 데이터가 Agent에 전달되는 과정

```text
업무 담당자
   │
   ├─ Word·PDF: 규정, 매뉴얼, 원문
   ├─ Excel·CSV: FAQ, 데이터, 평가 기준
   └─ 흐름도: 업무 절차와 승인 단계
                 │
                 ▼
        AI를 이용한 데이터 정리
                 │
                 ▼
       업무 담당자의 검토 및 승인
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
       RAG     데이터베이스   MCP·API
    지식 검색    데이터 조회    업무 실행
        │        │        │
        └────────┼────────┘
                 ▼
              전문 Agent
```


## 운영 원칙

- 업무 담당자는 Word, PDF, Excel과 같은 익숙한 형식으로 데이터를 제공합니다.
- AI가 데이터를 정리한 후에는 반드시 업무 담당자가 내용을 검토하고 승인합니다.
- 안정적인 지식은 RAG, 실시간 데이터는 데이터베이스, 실제 시스템 실행은 MCP·API를 사용합니다.
- 출처가 없거나 승인되지 않은 데이터는 정식 Agent 지식으로 배포하지 않습니다.
- 실행 작업 Agent는 분석·권고 Agent보다 높은 수준의 검증과 승인 절차가 필요합니다.
